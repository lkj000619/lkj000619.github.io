The person behind the projects

만드는 과정에
마음을 많이 씁니다.

아이디어가 실제로 동작하는 모습을 볼 때 큰 성취감을 느낍니다. 임베디드에 대한 관심을 대학의 로봇 동아리에서 직접 만드는 경험으로 옮겼고, 그렇게 쌓인 작업들이 이 포트폴리오의 중심에 있습니다.

참여하는 일에 책임감을 느끼고, 직접 기획하거나 오래 노력한 프로젝트에는 더 큰 애착을 갖습니다. 2021년 꼬꼬 MK2 ↗는 현장 합선으로 임무를 수행하지 못했습니다. 이 경험을 다음 로봇에 반영해, 2023년 MK3 ↗에서는 전원 계통을 분리하고 퓨즈 박스를 설계했습니다.

혼자 개발할 때는 ‘일단 해 보자’는 마음이 앞서 점검을 건너뛰고 시행착오가 커질 때도 있습니다. 시도 전에 구현 가능성을 살피고, 판단이 어려운 부분은 다른 사람과 이야기하는 방식으로 보완하고자 합니다. 동아리에서는 식사와 쉬는 시간에도 팀원들과 계속 기술 이야기를 나누며 아이디어를 다듬었습니다.

회사에서 영상을 다루며 컴퓨터 비전과 비디오 코덱, 데이터 압축에도 관심이 넓어졌습니다. 최근에는 AI 에이전트로 아이디어를 구체화하고 작은 프로토타입을 더 빨리 확인하는 방법을 찾아보고 있습니다. Codex Desk Meter ↗도 지금 만들고 있는 결과물입니다.

만들고 배우고 나눈 이야기

2017년, 고등학교 2학년 때 홈 자동화 연구 프로젝트 ↗의 아이디어를 제안하고 연구계획서를 작성했습니다. 팀장으로 방향과 문서, 운영을 맡았고, 설계와 구현을 주로 담당한 팀원들에게 C와 Arduino를 배웠습니다.

2019–2023년에는 로봇 동아리 ‘앙치킨’에서 국방로봇 대회를 준비했습니다. 대학 생활의 많은 시간을 동아리에 보내며, 여러 해에 걸쳐 로봇을 만들고 대회에 도전했습니다.

‘일단 해 보자’는 마음만큼, 구현할 수 있는지 확인하는 과정도 중요하게 생각합니다. 팀원들과는 작업 중에도, 밥을 먹으면서도 접근과 기술 선택을 계속 이야기했습니다. 지금도 혼자 생각하는 데서 놓치는 부분을 다른 사람의 피드백으로 발견하는 대화를 좋아합니다.

Verilog 핑퐁 게임

나의 역할 · 클럭 분주 · 입력 처리 · LED Matrix·7-segment 출력 경로

전공 팀 프로젝트 · 보드 게임 동작·점수 표시 확인

입력부터 실제 보드 출력까지 연결한 실습

  1. 스위치·키패드 입력
  2. 클럭 분주·게임 동작
  3. LED 화면·점수 표시

문제와 목표

3인 팀 전공 실습에서 LED Matrix로 게임 화면을 만들고, 키패드로 바를 조작하며 7-segment에 점수를 표시해야 했습니다.

구현과 문제 해결

  • 클럭 분주, 입력 처리와 LED Matrix·7-segment 출력 경로를 구현했습니다.
  • 택트 스위치로 시작하고 키패드로 바를 조작하도록 연결했습니다. 10×14 LED Matrix는 게임 화면, 8배열 7-segment는 점수를 표시했습니다.
  • 처음 공이 화면에 보이지 않아 클럭 분주를 다시 조정하고 실제 보드의 게임 동작과 점수 표시를 확인했습니다.

결과

교육용 보드에서 게임 동작과 점수 표시를 확인했습니다. 디지털 회로의 입력·타이밍·출력을 연결하고 화면 증상을 보며 수정한 경험입니다.

남은 검증과 한계

전공 실습 수준의 경험입니다. 보드·FPGA 모델, 개발 툴과 시뮬레이션·합성·타이밍 분석의 수행 범위는 기록에서 확인하지 못했으며, 이번 홈페이지 갱신에서 코드를 재실행하지 않았습니다.
